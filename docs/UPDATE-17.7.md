# V17.7 更新说明

结果数量分为全量已分析与当前筛选。流程一/二/三只包含各自分支，活动保持原样、预售、特殊SKU、异常等另行分类；筛选不能决定分析/导出的行数。新一次分析成功后恢复全部结果并清空旧搜索，显示全部按钮可一键清除筛选。分页仍每100条，导出遍历全部分析结果。

Windows透明圆角继续保留，由应用提供边缘缩放。原5px边缘增至10px，角落14px增至24px；窗口尺寸变化可能使DOM指针捕获丢失，此事件不再被直接视为松开。pointerup、mouseup、取消、无按键移动、Esc、失焦及页面退出会停止缩放。拖动中禁用文字选择，防止误选正文。最小尺寸由1100×700减至900×560，Windows小屏按可用工作区适配。

Mac原生框架缩放仍使用原生机制，最小尺寸同样调整；不增加二值区域裁剪或坐标反馈位置拖动。窗口拖动和大小变化仍需Windows10实机验收。
