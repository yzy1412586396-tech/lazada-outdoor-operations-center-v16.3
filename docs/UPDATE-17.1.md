# V17.1 · 活动低价提醒与交互优化

维护更新，小版本从 V17.0 增加 0.1，安装元数据 17.1.0。

## 活动报名

在店铺、控价库、控价类型等选择区域下方填写“报名价 ÷ 售价提醒值”，默认 0.95。接受任意非负有限小数，如 0.90、0.95、0.95555；空白、负数、无效输入不覆盖已保存值。菲律宾、泰国分别保存该设置。

系统生成报名价后，每行使用最终报名价除以原表识别的售价；人工报名价优先，修改后同步更新。比例低于提醒值时，整行高对比粉红背景、深红文字、红色边线及“低价提醒”标签显示。等于提醒值不提醒。无有效售价或报名价时显示“无法计算”，不会显示 Infinity。可通过“低于提醒值”筛选快速核对。

这项提醒仅用于界面确认，不自动剔除或取消勾选，不改变价格匹配、门槛和导出资格，也不写入报名原模板的颜色、备注或新列。比如售价 100、报名价 90、提醒值 0.95 时显示 90% 的低价提醒；改成人工报名价 97 后取消提醒。

未匹配 SKU 门槛规则只有小方框可切换，蓝色空白和标题文字均不触发开关。原门槛规则与本次提醒独立。

活动预设展开后，每个名称最右侧增加 × 删除按钮；直接删除并保存，选择当前预设后删除会回到“手动输入”，已填任务名称保留为可编辑文字。删除预设不会删除历史报名文件或任务记录。

## 流畅性与下载菜单

活动预览每页只绘制 100 行，筛选搜索延迟 140ms，分页复用筛选排序结果，人工输入通过事件委托更新。单次活动分析复用控价索引；修改活动设置不再重绘全站业务表格。导出使用完整 session，不受分页限制。

最近下载面板层级曾为 20000，右键菜单为 10020，导致被面板覆盖。本版菜单使用 Chromium 顶层 popover，并限制在视口内；复制路径、删除记录验证可点击，删除记录保留文件。

## 国家与数据

暂时只显示菲律宾、泰国。此前选中的马来西亚启动时回到菲律宾；马来西亚存储键与原数据保留，不迁入其他国家或清除。公司 MCP 在线自动改价保持暂停。

## 验证范围

菲律宾和泰国验证比例边界、任意小数、无效输入、零售价、人工改价、提醒筛选基础逻辑、205 行分页及全量导出、预设删除和重启持久化。提醒设置改变前后，报名导出各 ZIP 部件内容一致；隐藏工作表保留。

10,000 行结果压力测试始终只绘制 100 行，当前 Mac 测试的 DOM 翻页更新约 4–6ms；这只衡量测试环境的脚本/DOM 更新，不代表所有硬件或 Windows 的实际帧率。多库及原始商品表改价回归继续执行。五套主题的预览、预设、菜单截图已人工检查，并修复深色主题中提醒文字对比度。

Mac 和 Windows 包校验为同一业务源码，Windows 安装包仍未签名，未在 Windows 10 实机完成操作系统级视觉和流畅性验收。
