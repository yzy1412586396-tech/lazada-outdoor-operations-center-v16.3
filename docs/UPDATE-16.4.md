# V16.4 更新与验证

- 早鸟价选择保存在国家业务状态字段 repricingProtectEarlyBird，旧状态缺省为 true；切换国家读取各自值。选择变更后清除旧预览，重新分析才可导出新规则结果。分析期间禁用规则选择。
- 关闭后空白 SpecialPrice 进入原匹价分支；精确、店铺后缀、泰国尾码、组合数量合计仍由原引擎处理。匹配失败、冲突和无效价格保留原值。导出按分析快照执行；Price、SKU 与模板其他内容不改。
- 一次分析复用控价索引，每100行让出事件循环；预览分页每页100行，分页不限制导出行数。
- 拖动原来使用 clientX/clientY 与 IPC setPosition。窗口位置变化改变了 client 坐标，形成位移反馈；现删除这条链路，使用原生 app-region:drag。透明 Electron 窗口与大量 CSS 模糊的组合增加重绘压力，改用不透明窗口并移除模糊效果。尺寸边框交由系统控制。
- 真实模板294条SKU，SpecialPrice均空白；关系表4755个组合。两国以受控价格验证开启/关闭、直接与组合匹价、人工覆盖、取消应用、分页全量导出和重载设置。另各验证7项空白/非空、同价、冲突、无效、未匹配边界。
- 两国测试导出只有H5、H7、H169单元格改变；其他单元格、Price、SKU、隐藏工作表和其他ZIP文件部件均保持。保护模式无单元格改变。测试价格不代表正式控价。
- 原有整体 smoke test 通过，包括库存、活动价格边界、费用、SQLite schema 5 和桌面桥。UI 测试的拖动项改为原生区域配置检查；sendInputEvent无法证明OS实际拖动体验。5组窗口宽度检查通过。
- Windows运行库44.5.0官方SHA256通过。安装包未签名；Windows真机安装/升级和硬件流畅性需实机验收。原版安全审查中两项P1仍属于后续修复范围。
