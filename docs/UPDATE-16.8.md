# V16.8 · 2026-10-07

## 修改

- 将此前两次界面及窗口维护公告合并为 V16.8，保留 V16.4 及更早历史。显示版本 V16.8，安装元数据 16.8.0；以后小更新增加 0.1。
- 五套完整主题、思源黑体及思源宋体、三档字号、三种按钮形状保持可选并持久保存。
- 泰国默认标题筛选词只在新建国家数据时初始化。加载、国家切换和升级不再追加已删除词；用户保留的自定义词和空列表原样保存。已有版本丢失的删除意图无法恢复，本次不会猜测或清空已有关键词。
- 移除侧栏底部 SQLite 说明，导航及实际本地保存功能保留。
- 原山峰与太阳图案保留，背景改为浅灰蓝，山峰深蓝、太阳橙色；替换界面、Dock、Mac 应用和 Windows 程序/安装图标。原软件图标的方形底已改为 Mac 风格圆角方形，透明外侧由 SVG 几何轮廓生成，原山峰/太阳图像字节保持不变。已检查 32/64/128 像素及深浅背景下的 PNG 与 ICO。
- Windows 候选方案移除 SetWindowRgn/setShape 的二值裁剪。框架去掉 native thick frame，用 Chromium 角部 alpha 圆角绘制，内容保持不透明。八个边缘拖动入口只按屏幕坐标计算窗口尺寸，支持自定义最大化/还原；Mac 保持原生窗口圆角与拖动。
- 保留菲律宾、泰国全店改价早鸟价规则选择器及原有匹配、组合 SKU、原模板回填功能。

## 验证范围与发布状态

Mac 页面视觉检查已完成：五个主题 × 六个页面、字体选项截图，以及正式本地数据的公告和总览截图。截图由 Electron capturePage 获取，仅证明内容呈现，不是 Windows 外窗截图。系统屏幕录制权限尚未可用，因此没有桌面级外框截图。

筛选词测试：新建泰国系统有默认词、点击删除按钮成功、自定义和空列表在国家切换及页面重载后保持，两国独立。数据库及原有业务冒烟通过；两个用户输入文件参与改价回归，合成测试价格不能用于平台上传。

Windows PE 图标和版本资源已替换并读回校验；manifest/ASAR 资源逐字节保留。Windows 安装候选会继续校验 ASAR 内容及与源码的一致性，但**没有 Windows 10 测试环境，尚未完成 Windows 10 安装、外层边缘、高 DPI、拖动与缩放的真机视觉和流畅性验收**。未验收包留在内部工作目录，不提供为成品。

Windows 待验收：浅/深主题、四角在100%/125%/150%缩放及不同背景下没有白边/锯齿；八方向缩放连续稳定；最大化/还原、最小化/恢复和多显示器行为；现有数据覆盖升级、图标以及改价导出。

构建：`pnpm dist:win`，Mac `electron-builder --mac dir --arm64`。Windows 资源处理使用 [resedit-js](https://github.com/jet2jet/resedit-js)，避免依赖 Wine 修改图标。Electron 的透明窗口存在平台限制，不能仅据代码和 Mac 结果保证 Windows 体验，参见 [Electron 窗口样式说明](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles)。
