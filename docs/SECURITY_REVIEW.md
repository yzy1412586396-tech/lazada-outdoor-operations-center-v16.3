# V16.3 原版安全审查记录

本仓库和 Release 均保存本机正在运行的 V16.3.0 **原版快照**，未修改应用逻辑或重新生成安装器。以下问题由本次 Codex Review 在原版代码中发现，当前归档**没有修复**。在修复并验证以前，PR 保持草稿状态。

## P1：本机只读接口缺少访问认证

`electron/northstar-server.js` 的数据接口绑定 `127.0.0.1`，但没有对读取业务数据的请求做身份认证，同时响应允许任意浏览器来源跨域读取（`Access-Control-Allow-Origin: *`）。在浏览器允许访问本地网络的环境中，用户访问的网页可能读取店铺、SKU、价格和历史数据。修复版本应对数据接口进行认证，并限制允许的浏览器来源；还需要验证独立 Northstar 项目的接入。

## P1：自动化文件夹重新连接未核验来源

`electron/automation-folders.js` 的 `automation-folder:reconnect` 接受渲染进程提供的现有目录路径，未经可信保存记录核验就加入可访问目录。若渲染进程被恶意内容控制，后续扫描、读取或写入可能越过原本要求的用户选取目录边界。修复版本应只允许重新连接已由用户明确选择且持久保存的目录，并测试未授权路径会被拒绝。

这两项需要在后续修复版本中修改源代码、重新打包、测试，并更新安装器及哈希。本归档的 SHA-256 仅证明上传与本机原件一致，不代表代码安全审查通过。
