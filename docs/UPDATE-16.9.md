# V16.9 · Windows 四角修复候选版

版本按小更新增加 0.1：界面 V16.9，安装元数据 16.9.0。V16.8 公告及正常历史保留。

## 原因与修改

V16.8 将背景画在 body 上，再裁剪 body；浏览器可把 body 背景传播到根画布，绕过这层裁剪。在透明窗口渲染复现中，旧版四角 alpha 都为 255，即仍是方形不透明背景。不能据上方外窗圆角认定下方也已被裁剪。

V16.9 根节点及 body 保持透明，所有可见内容放入独立的固定圆角表面。表面与整个视口一致，四角统一 14 CSS px 圆角；动态插入的弹层也放入表面。主题、页面缩放、大小和焦点变化不依赖单独恢复裁剪区域。

启动与最大化后还原的窗口按显示器实际工作区限制尺寸和位置；最小尺寸适配小屏幕，避免旧的 1440×900 或已保存尺寸让下边缘落到可见区域外。这是针对“底部看不见”增加的保护；用户截图尚不能独立确定是否曾超出屏幕。

Windows 首次显示等待增强样式和脚本加载完成，避免初始化阶段绘制旧的方形背景。不透明的内容区、原生拖动、圆角软件图标、主题及业务逻辑保留。

## 验证

透明 Electron 窗口在 Mac 运行 Windows 表面路径进行渲染复现，检查了18张截图：五套主题×两种窗口尺寸，页面缩放 1/1.25/1.5、动态覆盖弹层、最大化、还原、失去焦点、最小化后恢复。每张截图四角 alpha=0，中心 alpha=255；表面宽高与视口完全一致。四角对比图是像素放大后的渲染截图，不是 Windows 10 桌面截图。

工作区限制、边缘缩放锚点、最小尺寸、最大化还原和监听器清理测试通过。菲律宾/泰国价格回归及业务冒烟通过。Windows EXE 图标/版本资源和安装载荷将读回校验，Mac 与 Windows 采用同一版本源码。

**Windows 10 的原生 DWM 合成、显示缩放、拖动流畅性仍待用户试用确认。**本包继续标记候选，不宣称 Windows 实机验收完成。

## 安装与试用

1. 在旧版“数据安全与备份”备份一次，退出旧软件。
2. 运行 V16.9 候选安装包，覆盖原安装位置，不需要卸载。
3. 确认界面显示 V16.9。
4. 先检查普通窗口下的四角、完整底部边缘；再切换浅/深主题，点击桌面使窗口失去焦点，再返回窗口。
5. 测试连续缩放、最大化/还原和最小化/恢复。如仍跳成方角，发整窗截图与短录屏，说明显示缩放比例和触发动作。

数据库和上传文件不随安装包分发，原应用名称及数据路径保持相同。软件未作发布者数字签名。
