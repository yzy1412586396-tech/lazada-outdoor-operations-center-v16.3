# V17.2 · 低价提醒纠正与置顶

小更新由 V17.1 增加 0.1，安装元数据 17.2.0。

此前空系统报名价被数值转换成 0，导致门槛不足和组合未匹配也显示 0% 并标红。本版保留空值，只有正数报名价和正数售价才能计算比例。不能报名或没有勾选导出的行不再标红；人工填写有效价格、通过原门槛检查且勾选后，再按比例判断提醒。

有效低价提醒在筛选后、分页前置顶，优先于主推异常。人工修改价格、切换提醒值、取消勾选后重新排序。等于提醒值不标红。预览排序不改变 Excel 原始行序，提醒颜色不写入模板。菲律宾和泰国使用同一实现。

代码注释位于 app/index.html 的 activityFinalPrice、activityPriceRatio、activityRatioWarns 及 renderActivityTable。测试覆盖空值、零价、未匹配、门槛不足、主推异常和取消导出；原有 205 行完整导出和 10,000 行分页性能测试继续保留。

V17.1 的预设删除、下载顶层菜单、主题与国家隔离继续保留，详见 UPDATE-17.1.md。Windows 10 实机环境仍不可用，不能将 Mac 上的渲染检查视为 Windows 原生窗口验收。
