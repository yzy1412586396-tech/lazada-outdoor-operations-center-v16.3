# V18.0 验证记录 · 2026-10-14

本机macOS / Apple Silicon，Electron44.5.0。独立测试profile，不修改正式业务数据库。

## 通过

- 确定性单元测试：上下架语义、10件边界、无替换改inactive但指定仓保留、指定仓全0不改状态、非指定仓清零、未匹配或冲突冻结、预售有货替换及提示、inactive人工同意/保持、黑名单优先、S后缀碰撞、人工库存校验、组合同仓。
- 源码及从Windows安装器实际提取的app.asar均运行四表全流程，共469商品行。逐行核对最终SellerSKU、status和库存值及类型；原模板行数不变。
- 独立Python/XML核对：冻结行原XML、非目标单元格、其他ZIP组件保持一致；缺货下架行指定仓原值保持、非指定仓0。测试中的上架同意、保持、人工库存和冻结选择只用于测试，不是用户正式决策。
- 国家/店铺隔离、共享仓库与组合来源、黑名单经SQLite存储恢复、不同店铺没有继承黑名单。菲律宾和泰国均可运行四表识别。
- 一万条模拟结果每页100条；提取包的JS预览生成测得13.5ms，四表分析23.5ms。这是本机测试中的处理时间，不等于整次导入/绘制时间或Windows实机帧率。
- 一万控价记录国家切换测试约0.3–6.3ms，隐藏模块没有额外渲染，保留当前页面及国家状态。
- 对最终Mac打包资源进行了实际桌面操作：SKU ID搜索、同意上架、人工库存输入及保存、×确认弹窗、恢复原值冻结、黑名单查看与移出、保持下架。视觉检查发现并修正主题覆盖提醒底色和理由/按钮排版；最终包重新确认强提醒整行颜色及固定×按钮。
- Mac部署前备份原应用和SQLite数据库，最终本地应用打开显示V18.0新核对模块。
- Windows安装器提取asar与win-unpacked一致，Mac/Windows业务JS、样式、字体和图标逐字节一致；无xlsx、db、sqlite或env文件打入包。
- 不透明原生窗口可调整/可最大化属性、原生最大化与还原、旧JS边缘拖动覆盖移除检查通过。

## 未验证范围

没有可操作的Windows10实机，因此未在Windows10运行安装器或人工拖动八边角验证。Mac上的Windows样式路径和静态窗口参数验证不能替代该项；发布附件标记Candidate。安装器没有代码签名。用户数据、四表文件、数据库、逐行结果和含商品数据截图仅保留本机。
