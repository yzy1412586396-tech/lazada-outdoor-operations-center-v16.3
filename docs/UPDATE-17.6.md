# V17.6 更新说明

仓库模板按国家共用。初次升级从当前国家已有店铺配置迁移优先选择已完成的仓库对应；之后每次修改共用模板，不再为每家店重新初始化。店铺库存列通过表头重新对应，不能只按旧列号盲填；两个国家的仓库模板、特殊规则和源文件分别保存。

活动中商品已开预售：整行保持原样，不列入人工名单。未预售且已确认库存不足：优先找同款，再找明确设置的关联SKU；有单指定仓库存大于10的替换项时修改SKU及仓库库存。没有替换项才保持原样并列入活动缺货人工处理。已全零处理过的行继续跳过。库存来源未知不能等同于已确认缺货。

格式特殊的SKU单独显示特殊提示，不属于异常或人工处理；保留原行XML。跳过识别规则支持完全匹配与包含匹配，按去空白、大写的SKU字符比较，命中保留整行，包括原多仓库存。保留原样的行是多仓清零规则的明确例外。

关联SKU为原SKU→替换SKU，不递归执行关联链。仅作为自动同款失败后的后备，目标要在最新马帮数据中有单仓大于10的可用量，不能凭用户输入虚构库存。组合目标必须所有组件在同一实际仓库组成超过10套。原后缀保留，重复时分配未占用S1/S2等；Status、SKU ID、价格及其他业务列保持不变。已预售、格式特殊、跳过识别、已处理行不应用关联。

特殊SKU设置默认收起，展开可新增和删除规则。同一国家店铺共用规则，另一国家独立。页面移除长流程与实现说明，单一仓库输入既可输入关键字，也可通过箭头从完整仓库列表选择。
